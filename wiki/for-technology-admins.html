    For technology admins

    Set up DrawSplat for your school, connect accounts, and keep saved work safe. Choose the hosting path first, then test it with a teacher and student account.

    Choose your setup

    Setup What it provides Guide
    Browser only Whiteboard tools and files saved on a device. No server or accounts are needed. Browser-only setup
    Complete district suite School-hosted apps, database-backed whiteboard saving, and classroom workflows. Choose Docker or a native install. District installation and Quick Start
    Individual apps Selected apps served from your own website. Modular self-hosting
    Apps Script connection Optional Google Drive and Sheets workflows. This is separate from district database hosting. Apps Script setup

    Get current packages from Downloads. The complete suite includes SplatWorks; choose the components your school needs.

    Connect saving and school accounts

    • Follow MySQL / MariaDB setup to finish first-time setup and create the district administrator account.
    • Set up classrooms and rosters. Import a roster CSV or use supported Google school sign-in after configuring it.
    • Review Google OAuth permissions. School sign-in and Google Drive access use different permissions.
    • If you use Apps Script, follow the Web App URL guide and the technical reference.

    Teachers should use the school sign-in path you set up. Do not share the district administrator password with classrooms.

    Review privacy and access

    Start with Compliance and district review. It explains which controls apply to each storage path. Use the NDPA / DPA review packet when reviewing an agreement.

    The Apps Script Compliance Console manages its own Google-backed workflows. It does not manage the district database’s private boards or classroom tables. Set and document your district’s access, retention, export, and deletion procedures.

    Publish a clear contact and request process for families. The Parents and students guide explains where to start.

    Check before classroom use

    • Confirm secure website access and the correct school sign-in settings.
    • Test teacher and student access with separate accounts.
    • Save a board, reopen it, and test an assignment and turn-in.
    • Make a backup and test recovery. Restart the services and confirm saved work remains.
    • Check the expected classroom load and review known compliance gaps.

    The installation guide includes backup, restart, and update steps. Keep passwords and backup files private. Hosting the SplatWorks apps does not automatically add database saving to each app.

    Maintain the service

    Check release notes before updates. Keep a backup, test changes, and confirm the school’s key workflows afterward. See licensing for source and license duties, or contact support for help.
