Basic Tutorial

  1. Create or update the school Apps Script backend with apps-script/Code.gs, then deploy it as a Web App.
  2. Use the one-time setup password to unlock this instance admin page.
  3. Sign in with Google. That Google account becomes the DrawSplat Hub instance admin after the backend verifies the token.
  4. Paste the Apps Script Web App URL and test the connection.
  5. Use the generated teacher/student links for DrawSplat Hub classrooms.

Free Classroom Use

Individual classroom teachers can run their own DrawSplat Hub classroom for free, even when they are not connected to a campus or district account.

Optional support helps keep DrawSplat free for teachers who need it.
