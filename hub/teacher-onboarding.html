DrawSplat Hub

Teacher onboarding checklist

Use this process when adding an individual classroom teacher from the Hub admin account, then handing off ownership when the teacher is ready.

Instances Admin Hub Splash

Recommended Package

  • Create the teacher folder. From drawsplat@gmail.com, create a folder named for the teacher or classroom, such as Teacher Name - DrawSplat Hub.
  • Create the teacher data file. Add the Google Sheet or Drive files that will hold that teacher's DrawSplat classroom data.
  • Create the Apps Script backend. Prefer a standalone Apps Script project for easier sharing and ownership transfer. If using a Sheet-bound script, remember that the script follows the container Sheet.
  • Create or update the config. Make sure the teacher's instance config points to the correct Apps Script Web App URL or storage backend.
  • Share first as editor. Share the folder, Sheet, config file, and Apps Script project with the teacher as editor before asking them to use the instance.

Ownership Handoff

  • Confirm the teacher can open everything. Ask the teacher to open the folder, Sheet, Apps Script project, and DrawSplat instance before transferring anything.
  • Transfer ownership where Google permits it. Transfer the folder, Sheet, standalone Apps Script project, and config file individually. Folder ownership alone may not transfer every file inside it.
  • Check domain limits. Google may block ownership transfer across Workspace domains or between some Workspace and consumer Gmail accounts.
  • Use copy-as-owner if transfer is blocked. If Google will not transfer ownership, have the teacher make copies from the shared package. The teacher owns the copies they create.
  • Update the Hub record. Once the teacher owns or controls the copied package, update the Hub instance config and notes so future support points to the teacher-owned resources.

Practical rule: start with editor sharing from drawsplat@gmail.com, then transfer ownership only after the teacher confirms access. If transfer fails, the teacher-owned-copy path is the reliable fallback.
