# DrawSplatTM v3.1.15 Release Notes

Released: 2026-06-29

## Highlights

- **WriteSplatTM packaged.** WriteSplatTM is now available as its own SplatWorksTM self-host ZIP alongside GridSplatTM and ShowSplatTM.
- **WriteSplatTM classroom writing app.** Adds the browser writing workspace, local autosave, `.writesplat.json` files, readability cards, classroom templates, teacher tools, read-aloud controls, vocabulary highlights, Markdown Studio-style import, and practical export formats.
- **ShowSplatTM updates packaged.** Includes import/export menu grouping, PPTX/ODP first-pass compatibility, image-based PDF import, browser PDF export, selected text-box controls, zoom, last-slide delete safety, auto-hiding presenter controls, task-focused Help, and the Help menu stacking fix.
- **SplatWorksTM package refresh.** The release includes four self-host artifacts: DrawSplatTM, GridSplatTM, ShowSplatTM, and WriteSplatTM, plus a checksum file.

- `splatworks-gridsplat-selfhost-v3.1.15.zip`

## Notes

- SplatWorksTM apps remain packaged separately so schools can update the spreadsheet, presentation, or writing app without redownloading the full DrawSplatTM whiteboard/tools/widgets/games bundle.
- WriteSplatTM is GPL-3.0-only as part of the SplatWorksTM app family.
- DrawSplatTM whiteboard code, tools, widgets, games, backends, and compliance features remain under the repository-level DrawSplatTM license unless a file or subdirectory says otherwise.
