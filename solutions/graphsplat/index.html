GraphSplat function reference

Constants: pi (π), tau, e, phi

Trigonometry: sin, cos, tan, cot, sec, csc, asin/arcsin, acos/arccos, atan/arctan, atan2

Hyperbolic: sinh, cosh, tanh, sech, csch, coth, asinh, acosh, atanh

Numeric: sqrt, cbrt, root, abs, log, logbase, ln, exp, floor, ceil, round, sign, mod, clamp, hypot

Combinatorics: factorial, ncr, npr, gcd, lcm

Statistics: mean, median, sum/total, product, variance, stdev, mad, min, max, erf, gamma

Use variables x, a, b, and c, implicit multiplication such as 2x, and a domain restriction such as {x>0}. GraphSplat evaluates scalar curves locally; list, distribution, regression, and simulation workflows belong in the Data and Specialty workspaces.
