# GraphSplat

GraphSplat consolidates DrawSplat's Graph Maker and Picture Graph Maker into one privacy-first browser application.

## Workspaces

- Quick charts: bar, horizontal bar, line, area, pie, donut, and XY scatter
- Picture graphs: emoji or uploaded pictures, configurable key, and partial symbols
- Coordinate plane: click-to-plot points, labels, connected points, and linear equations
- Expression calculator: multiple functions, parameters/sliders, pan/zoom, roots, intersections, and a value table
- Specialty charts: bubble, radar, polar, stacked bar, stacked area, and pyramid

Graphs export as PNG, JPEG, SVG, printable PDF, or CSV. Projects can be saved locally or moved between devices as JSON. No graph data or uploaded picture is sent to a server.

## Design references

The interaction model was informed by the capabilities described by [NCES Create a Graph](https://nces.ed.gov/nceskids/createagraph/), [Desmos Graphing Calculator](https://www.desmos.com/calculator), and the graphing tools summarized in [TCEA's Five Simple Graphing Tools](https://blog.tcea.org/five-simple-graphing-tools/). GraphSplat contains an independent implementation and does not copy their code, visual interface, assets, or branding.
