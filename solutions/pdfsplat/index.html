    Protect or unprotect a PDF

    PDFsplat uses CipherSplat to protect a PDF inside an authenticated, encrypted .csplat package. The PDF is encrypted locally with AES-256-GCM; neither the PDF nor its password leaves this device.

    Password safety

    • Use a unique password of at least 12 characters. A password manager can create and store one.
    • Send the protected file and password through different channels—for example, email the file and share the password by phone.
    • PDFsplat cannot recover a forgotten password. Test unprotecting the download before deleting the original PDF.

    Generate a secure password with CipherSplat ↗

    CipherSplat derives the encryption key with Argon2id and protects the PDF with authenticated AES-256-GCM encryption.
