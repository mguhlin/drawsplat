    Your files stay here

    PDF bytes, page images, extracted text, and edits are processed in this browser. DrawSplat does not upload your PDF.

    This prototype stores no document or recovery data after the tab closes.

    Separate PDF

    Create new PDFs without changing the open document.

    Crop selected pages

    Enter margins as percentages of each page. Cropping changes the exported page boundary without changing the source file.

    Deskew / custom rotation

    Use a small positive or negative angle to straighten selected scanned pages.

    Add signature

    Add a typed signature or place a PNG/JPEG signature image. It remains movable and resizable until export.

    Headers, footers and page numbers

    Apply text to the selected pages. Use {page} and {pages} as placeholders.

    Sanitize PDF copy

    PDFSplat will rasterize the edited pages into a new PDF. This removes document metadata, scripts, attachments, forms, annotations and hidden content.

    The sanitized copy will no longer contain searchable or selectable text. Keep the original until you verify the result.

    Convert PDF to EPUB

    Create a reflowable EPUB 3 ebook from the open PDF. Conversion happens entirely on this device.

    Use a language tag such as en, es, or en-US.

    Best for searchable, single-column, text-first PDFs. Scans need OCR first; tables, columns, equations, and precise page layout may be simplified.

    Protect or unprotect a PDF

    PDFsplat uses CipherSplat to protect a PDF inside an authenticated, encrypted .csplat package. The PDF is encrypted locally with AES-256-GCM; neither the PDF nor its password leaves this device.

    Password safety

    • Use a unique password of at least 12 characters. A password manager can create and store one.
    • Send the protected file and password through different channels—for example, email the file and share the password by phone.
    • PDFsplat cannot recover a forgotten password. Test unprotecting the download before deleting the original PDF.

    Generate a secure password with CipherSplat ↗

    CipherSplat derives the encryption key with Argon2id and protects the PDF with authenticated AES-256-GCM encryption.
