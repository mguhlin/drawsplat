# VideoSplat functionality audit — September 29, 2026

## Fixed findings

- **Insert could overlap existing footage.** Inserting a clip inside another clip shifted only clips beginning after the playhead. Insert now splits the intersected clip and moves its remaining footage after the inserted material, preserving source offsets. Media-bin insertion uses the same engine as clipboard insertion.
- **Overwrite removed too much footage.** Pasting a short clip in overwrite mode deleted entire intersecting clips. Overwrite now removes only the covered interval and keeps the original footage before and after it.
- **Track locks did not protect selected clips.** Locking a track after selecting its clip left inspector, keyboard, and destructive edit paths available. Locking clears the active selection; the editing engine also rejects mutations of locked-track clips.
- **Malformed project imports could crash the editor.** Version 2 manifests were accepted without a canvas or valid nested tracks; version 1 migration bypassed basic validation. Both versions now validate required canvas, settings, media, track, clip, and property data before replacing the current edit. Asset, track, and clip IDs retain separate namespaces for compatibility.

Regression tests demonstrate the insert, partial-overwrite, locked-track, and malformed-manifest failures against the previous implementation. Browser tests verify insert and overwrite timing in downloaded project JSON, undo, media-bin insertion, locked-track protection, and preservation of the current project after a rejected import.

## Audit scope and limits

Covered local imports, timeline editing and undo, project download/recovery, offline startup, privacy request checks, recording permission failures, synthetic screen/camera capture, audio retention, crop review, interruption recovery, optimization, green screen, subtitle workflows, export cancellation/errors, WebM output, and supported MP4 paths.

The subtitle test was updated to expect the existing acceleration preference in worker messages. The direct-insertion test now expects the three clips produced by splitting an intersected clip.

Recording tests use synthetic video/audio streams. They do not certify a physical camera, microphone, operating-system screen-share chooser, background capture on every device, or GPU hardware performance. Phone tests emulate devices. Real speech-model downloads/inference, the nine-minute recording soak, and the twenty-minute video exceeding 512 MB remain opt-in and were not run in this audit.
