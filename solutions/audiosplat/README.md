# AudioSplat

AudioSplat is DrawSplat's private, browser-based multitrack audio recorder and
editor. Audio is processed locally and no account or backend is required.

## Development

```bash
npm install
npm run dev
npm test
npm run build
```

The production app is hosted at `/solutions/audiosplat/`. The canonical product
and release checklist is in `docs/plan.md`.
