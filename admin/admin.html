Prepare your storage

In your classroom Sheet, open the new DrawSplat → Prepare classroom storage menu. One click creates the tabs and Drive folder DrawSplat needs.

In Google SheetsDrawSplat → Prepare classroom storage

Google will ask you to approve access to your Sheet and Drive. Use the teacher account that will own the classroom work. Review the permissions before allowing them.

School account blocked? Ask your technology team to allow the script. If Google shows an unverified-app message, follow your school's approval process.

I do not see the DrawSplat menu

Reload your Sheet. If the menu is still missing, reopen Extensions → Apps Script, select setup in the function list, and click Run. Approve Google's permissions, then return here.

Publish your connection

Open Extensions → Apps Script in your classroom Sheet. Follow these choices in Google's publishing window:

1. Open publishingDeploy → New deployment
2. Select type (gear icon)Web app
3. Execute asMe — your teacher account
4. Who has accessYour school's approved classroom setting

DrawSplat's connection test needs to reach the web app without a Google sign-in redirect. Ask your technology team which access setting your school allows; a restricted deployment may not work with the browser connection.

Click Deploy and approve any requested permissions. Copy the Web app URL ending in /exec, then come back here.

Advanced settings — storage, servers, and game access

Storage Mode

Choose how this browser-backed deployment should preserve work. Google is best for cross-device classroom rooms. Browser-only timed sessions are useful for simple shared devices or temporary workshops.

Open MySQL Wizard

MySQL online saving works with Railway, DigitalOcean, or your own server. Use the MySQL Wizard to test and enable the connection. Standalone folder storage still needs its own backend.

Advanced / Self-Hosted

MySQL Backend

Use this only when a district or self-hosted deployment has a real backend server. Most classroom teachers do not need this section.

MySQL Backend

Use Railway, DigitalOcean, or an existing MySQL server for private account-owned Save/Open. The browser stores only the public API endpoint. Database host, username, and password stay on the backend server in an environment file.

Open MySQL Wizard Backend Guide

Google Apps Script and MySQL are separate provider choices. MySQL does not enable Google classroom rooms or turn-in/review, and changing providers does not migrate saved boards.

Standalone Direction

The static admin page is an interim separation. The standalone target is a real admin dashboard with SSO, server-side permissions, realtime rooms, and provider integrations hidden from students.
