Admin Access

Teacher Admin is password protected.

Admin access is for teachers, facilitators, and deployment managers who need to configure Google Apps Script, MySQL, storage modes, classroom links, or privacy settings.

No password? On the admin login page, click Preview as Viewer for a read-only tour of the panel layout. No backend data is loaded in preview mode — it's safe to share with anyone curious about what teacher admin looks like.

To request access for real edits, use the DrawSplatTM contact form.
