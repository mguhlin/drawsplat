# DrawSplat v3.1.28 — Clear offline choices and root shortcuts

September 25, 2026.

- Renamed the download section to Individual apps and added CipherSplat’s dedicated offline download with measured ZIP/unpacked sizes.
- Each app explains whether it opens directly from disk or requires the included local launcher (Python 3).
- Every package includes OPEN-APP.html. Individual packages without an existing root index also include an index.html shortcut. Hosted shortcuts open the app; direct-file shortcuts open supported apps or local-launcher instructions.
- Complete DrawSplat and Tools include named root shortcuts for VideoSplat, MediaSplat, AudioSplat, PDFSplat, and CipherSplat. A dedicated CipherSplat offline edition is included beside its hosted app.
- PDFSplat and CipherSplat support direct-file use in tested desktop Chrome and Firefox. AudioSplat, VideoSplat, and MediaSplat require a localhost launcher for offline use. A web link cannot start Python or bypass browser file-origin restrictions.
- All thirteen self-host archives and the CipherSplat offline ZIP are refreshed. Internet is still needed for online services and first-time speech-model downloads; capture permissions remain browser-dependent.
