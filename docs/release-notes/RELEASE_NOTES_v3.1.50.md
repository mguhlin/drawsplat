# SplatWorks v3.1.50

GraphSplat adds **Equation Studio** for LaTeX authoring with fraction, root, power, subscript, inequality, matrix and aligned-step templates. Eight editable examples cover classroom mathematics from fraction addition through calculus. Copy LaTeX or structured MathML; export PNG, JPEG, SVG or printable pages; save an editable GraphSplat project. Read description speaks teacher-supplied text with available local browser voices. See the [equation guide](../graphsplat-equations.md) and [engine attribution](../../solutions/graphsplat/MATHJAX-NOTICE.md).

GraphSplat now restores a saved project's workspace and custom description, escapes expression-table and error text, handles a malformed saved-project index, and respects the real-number domain of nth roots.

WriteSplat, ShowSplat, ListSplat, GridSplat, VideoSplat, SplatBot Studio, Dicebreakers, Bingo Caller and the admin gate remain usable when optional browser storage is unavailable. Failed office autosaves give file-download recovery guidance. Transferred office projects stay isolated from the original draft even if session storage is blocked. ListSplat can start despite a malformed browser draft without deleting that stored copy.

Bingo Caller generates distinct numbers within each column, reconnects its broadcast channel when changing rooms, releases old channels, tolerates invalid saved games/cards, and preserves cleared marks across reloads.

The downloadable modules and complete district suite are refreshed with measured sizes and SHA-256 checksums. The separate next-generation plan remains proposals only. Existing accessibility and localization gaps remain documented; this release makes no accessibility-conformance claim.
