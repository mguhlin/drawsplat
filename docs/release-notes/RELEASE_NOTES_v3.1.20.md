# DrawSplatTM v3.1.20

DrawSplatTM v3.1.20 brings the post-v3.1.19 media and document work into a current, verified self-host release.

## Highlights

- Added MediaSplat for local browser media inspection, conversion, trimming, splitting, and multi-part ZIP creation.
- Added a Cloudflare-deployable split FFmpeg runtime for MediaSplat.
- Added VideoSplat for private browser video editing, analysis, anonymization, project storage, and export.
- Added DOCX and ODT export to Markdown Studio.
- Added independent MediaSplat and VideoSplat self-host ZIPs.
- Rebuilt the full DrawSplat, SplatWorks suite/app, Tools, Widgets, Games, AudioSplat, VideoSplat, and MediaSplat packages.

## Verification

The release includes `SHA256SUMS-v3.1.20.txt` covering all twelve ZIP artifacts. Core MediaSplat and VideoSplat processing remains in the browser without a required account or remote processing backend.
