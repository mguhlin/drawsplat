# DrawSplat v3.1.29 — Four typing adventures and current downloads

October 8, 2026.

- Typing Games is a menu with original hero artwork, four standalone pages, instructions, and six interface languages.
- Cipher Chase: overhead spy driving, lane controls, civilian traffic, shields, smoke, TEKS subject/grade choices, success definitions, and an enabled-by-default sound system with playback test and error feedback.
- Wordfall Reactor: 15×15 word board against a computer, seven-letter practice racks, validated crossing words, bonus squares, move history, 95 everyday words by default, optional TEKS vocabulary, and definition-only hints that do not supply words or placements. The optional word bank still offers guided placement.
- Story Sprint: passage practice with speed/accuracy feedback, deliberate next passage, and local TXT/CSV/JSON/XLSX imports. Pasting and dropping answers are blocked in scored practice; teacher imports still accept pasted text.
- Paws & Keys Adventure: kitten/puppy characters for ages 4–9, 12 progressive trails across four worlds, finger hints, saved stars, and optional spoken key hints.
- TEKS includes 72 curated English terms across science, math, and social studies/history for bands 3–5, 6–8, and 9–12, with original definitions and official TEA source links; it is not exhaustive curriculum coverage.
- Title-matching game URLs are canonical. Legacy links redirect until April 8, 2027, midnight America/Chicago, preserving query strings and fragments; afterward they display a manual link.
- Homepage, navigation, feature cards, search/action descriptions, teacher visibility controls, blog/RSS, README, and self-host documentation now describe the new collection.
- All thirteen core self-host archives are refreshed. Full DrawSplat and Games include game artwork, word banks, shared styles/scripts, and import dependencies. ClipSplat is included in full/Tools and also has a separate ZIP and checksum file.
- Local games use the supplied Python 3 HTTP launcher; retain the provided folder paths. Online services and first-time speech-model downloads still need internet.
- Whiteboard and app versions remain independent of this package release.
