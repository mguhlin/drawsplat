# v3.1.42 — LayoutSplat v0.5.0

October 16, 2026. LayoutSplat adds experimental in-app Publisher 2000 `.pub`
export, reusable Publisher source masters, matching shared-source text-ID linking
and dynamic master-page folios. PUB has native editable Unicode text/basic shapes,
bitmap fallbacks and fingerprinted native-project recovery; unsupported content
and target-application differences appear in the conversion report. LibreOffice
opening is verified. Microsoft Publisher itself still needs external validation.

The user completed a real Google Drive upload/download/reopen. The downloaded
project passed archive and native-model validation. Updated documentation explains
Drive's ZIP preview, reopening the whole project and the current PUB limits.

69 Chromium workflows, three focused Firefox workflows, model checks, independent
PDF/PPTX/ODP/GIF inspection and 10 printer-preflight tests passed. Broader Publisher
composition, proprietary native formats, richer suite exchange, large-document
workloads and commercial-printer acceptance remain on the roadmap.
