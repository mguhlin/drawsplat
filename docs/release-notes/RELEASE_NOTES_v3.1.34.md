# DrawSplat v3.1.34 · SplatWorks file exchange and Wiki updates

- GridSplat imports and exports XLSX and ODS, including common formulas, basic formatting and merged cells. Native project files retain dimensions and formatting.
- Whole-row and whole-column selection, Shift-click extension, range references, insert/delete, fill formulas or number series, and selected text replacement.
- WriteSplat DOCX table, hyperlink and ordered-list round trips improved; DOCX and ODT exchange supported.
- Recognized Office and native SplatWorks files open in the matching app in a new tab. Existing saved projects remain intact; save imported session drafts before closing. The matching app must be installed at the same origin.
- ListSplat exchanges Access/Base table records through CSV, not full database files.
- Wiki language controls, grouped FAQs, concise audience guides and current app format guidance. Sidebar has a single FAQ link; section jumps remain in the article.
- DrawSplat blog imports published MGuhlin.org DrawSplat/SplatWorks posts hourly, retains publication dates and excludes future posts.
- Static packages rebuilt; district suite v1.2.3 contains the current guide, launchers and applications.

## Conversion limits

Keep original Office files. GridSplat reads the first worksheet; 20 MB imports, up to 2,000 rows, 200 columns and 100,000 cells. Advanced formatting, macros, charts and media can change during conversion. No new cloud provider approval or district OAuth certification is implied.

Current guidance: [DrawSplat Wiki](https://drawsplat.org/wiki/), [Downloads](https://drawsplat.org/pages/download), [SplatWorks](https://drawsplat.org/pages/splatworks).
