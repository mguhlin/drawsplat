# PlanSplat v1.0.0

PlanSplat adds a student planner to SplatWorks: assignments, exams, projects, courses and class times, Today/Upcoming/weekly schedules, checklists, priorities, study blocks, recurring tasks, routines and a focus/break timer.

Google sign-in discovers and loads the account's planner. Changes save locally and automatically update Google Drive while authorization is active. A stable recovery file per browser protects concurrent edits. Reconnect when Google authorization expires; pending edits remain in the account's device draft. The app includes conflict review, account separation, sign-out, deleted-item restoration, JSON backups, CSV import/export, calendar export and printing.

Open [PlanSplat](https://splatworks.org/plansplat/) or read the [student guide](https://splatworks.org/wiki/plansplat.html). The standalone ZIP includes a Python 3 local launcher, app source and license notices. Self-hosted Google access requires an OAuth client configured for that exact origin. Existing v3.1.43 suite downloads retain their published contents.

Validation: 5 model workflows, 13 Chromium planner workflows, 46 shared wiki/navigation checks and a standalone create/reopen proof with external networking blocked. Google API simulations exercise discovery, repeat updates, expiry/reconnect, offline drafts, overlapping saves, account switching and sign-out. Actual Google personal/school-account acceptance remains pending a user-run trial. Interface: English. Notifications require an open app and browser permission. Application license: AGPL-3.0-or-later.
