# DrawSplat v3.1.31 — PDF presentations and WebDeck export

PDFSplat adds **Present PDF** and **Full screen** with page-by-page viewing of the current edited PDF. Navigation, Home/End, black/white blanking, control hiding, and Escape leave editing state and undo history intact. Browser full screen depends on support and permission; the page-filling viewer is the fallback. Timed playback supports a 1–3600 second interval and optional looping, and stops at the last page by default.

**Save as → WebDeck v5 (.html)** generates one self-contained, offline HTML presentation. Edited page images retain order, rotation, crop, and annotations, fit within the slide without distortion, and are capped at a 1200-pixel longest edge. WebDeck navigation, notes, presenter view, and printing are included. Page text is rasterized; notes start empty and do not copy hidden PDF text. ShowSplat imports the resulting HTML.

The interface additions include localized controls and status messages. Existing PDF, image, document, and EPUB exports remain available. Local rendering does not upload documents or invoke an AI service.

The READMEs, classroom walkthrough, ELE teaching suggestions, release notes, blog feed, menus, and download descriptions are updated. All thirteen core packages plus standalone ClipSplat are refreshed; the dedicated CipherSplat offline package remains included with its checksum. Whiteboard and individual app versions are independent of this package version.
