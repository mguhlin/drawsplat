# v3.1.35 — SplatWorks ecosystem and LayoutSplat v0.3

October 14, 2026. All 16 app/collection download ZIPs are refreshed; LayoutSplat
now has its own standalone package and ships in the five-app SplatWorks suite.
Complete district installation is refreshed separately as district-suite-v1.2.5.
Existing school data, backend identifiers, and DrawSplat whiteboard/tools remain
compatible. The website, Wiki, and blog use SplatWorks branding and the supplied
glossy purple logo. Both drawsplat.org and splatworks.org serve the deployment.

LayoutSplat adds 305 designs, descriptive titles with industry filters, 42 menu
presets, six business-card compositions with replaceable logos, 29 Avery sheet
layouts/127 product codes, name badges, printer offsets, and used-label skipping.
File groups Templates, alphabetic Import, page/print controls, and Export/HTML.
Right-click can link or unlink text boxes. Serif/sans, kerning, tracking, word
spacing, horizontal scale, ligatures, and embedded local fonts improve typography.

Publisher remains browser-native, with bitmap-fill/crop/paragraph accuracy fixes.
Legacy Pages XML, PDF-compatible Illustrator, all-page PDF artwork, and local
EPS/PS conversion are added. Native INDD/QXP and modern Pages IWA remain unsupported.
