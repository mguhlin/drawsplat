# ListSplat v0.2.0 — classroom data and relationships

October 26, 2026. This is an independent ListSplat app/module release; the general
SplatWorks suite ZIPs remain v3.1.45.

- 15 classroom starters, 17 tables and 204 practice records; every template table has 12 records.
- The default Animals starter now has 12 records. Existing saved projects are preserved.
- Six additional single-table activities: weather, gardening, budgeting, reading goals, jobs and makerspace inventory.
- Two connected examples: Library Books & Loans and Investigations & Trials, with 12 parent and 12 child records each.
- Appropriate numeric/date field types, teacher reflection questions and fresh identifiers on every template load.
- Primary/foreign key badges, field diagrams, one-to-many and one-to-one relationships, name/ID pickers, referenced-record protection and examples based on loaded tables.
- Markdown paste/file import, multiple-table choice, typed column preview, new-table and append workflows; CSV/TSV remains available.
- Nine views, clearer purple styling/icons, reversible table-tab closing, dialog close buttons and file actions in File.
- README, classroom walkthrough, component feature catalog and standalone downloads updated together.

The standalone ZIP includes source, tests, app licenses, required shared resources,
a Python 3 local launcher and SHA-256 checksum. Extract the entire archive and use
START-HERE.html; for hosting upload all included folders. Local edits and bundled
examples work offline. Optional Google Drive saving needs internet access and an
OAuth client configured for the installation origin. Native .listsplat.json
projects retain version 1 and reopen normally. CSV and Markdown do not preserve
relationship schemas; use the native project format for a full backup.

People, books, observations and measurements are fictional practice data. State
capitals and animal notes should be verified and sourced as part of research.
