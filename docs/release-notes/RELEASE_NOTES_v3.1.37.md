LayoutSplat v0.4.6 and WriteSplat v0.2.0 are now included in the refreshed self-host packages. LayoutSplat adds browser-native legacy QuarkXPress import, formatted Word/LibreOffice insertion, source-font matching, richer suite text exchange, updating folios, reading-order controls, and stronger print preflight. WriteSplat adds blank documents, page outlines, a ruler, indents, and paragraph tabs.

The release includes all 16 application/collection ZIPs, a README, and a combined SHA-256 list. The five-app suite includes LayoutSplat. The separate complete district release is `district-suite-v1.2.7`.

Validation includes 32 offline Chromium/Firefox package startup checks, 12 focused standalone LayoutSplat workflows, four district Quick Start checks, and the source milestone’s 52 browser/10 model checks plus independent PDF proofs. Packages were built from committed `e2eb037`.

[Illustrated feature guide](https://splatworks.org/wiki/layoutsplat-features.html) · [LayoutSplat blog walkthrough](https://splatworks.org/blog/microsoft-publisher-retiring-layoutsplat.html) · [Current format limits](https://splatworks.org/wiki/layoutsplat-import-accuracy.html)

Native Quark support is limited to 3.1–4.1. Native INDD and modern Pages IWA remain unsupported. Import fidelity and commercial print acceptance require review; the PDF/X helper is not independent certification. LayoutSplat requires its supplied local HTTP launcher for offline use. Retain bundled runtime folders and license/source notices.
