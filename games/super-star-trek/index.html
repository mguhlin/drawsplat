Decimal courses are allowed. Course 1.5 is halfway between courses 1 and 2. One warp factor is roughly the size of one quadrant.

Long Range Scan Codes

Each three-digit code is KBS: hundreds are Klingons, tens are starbases, and units are stars. For example, 207 means two Klingons, no starbases, and seven stars. Romulans cloak from long-range scans and appear only in the local sector display.

Library Computer

Computer options: 0 record, 1 status, 2 torpedo data, 3 starbase nav, 4 direction/distance calculator, 5 region map.
