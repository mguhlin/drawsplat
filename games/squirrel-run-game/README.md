# Squirrel Run — DrawSplat Games Starter

A standalone HTML5 canvas game draft for DrawSplat Games.

## Files

- `index.html` — playable game; no external libraries.
- `assets/` — original transparent PNG sprites.
- `assets.json` — sprite manifest.

## Gameplay

Move the squirrel across three lanes of traffic. Avoid cars, trucks, cats, and dogs. Collect acorns for points. Reach the tree hollow to advance levels.

## Controls

Arrow keys, WASD, or on-screen touch buttons.

## Integration idea

Place this folder at `games/squirrel-run-game/` in the DrawSplat site and add a Games menu link:

```html
<a href="../games/squirrel-run-game/" target="_blank" rel="noopener noreferrer">Squirrel Run</a>
```

## Asset note

All sprites in this package are original generated PNG files for this draft and are safe to use as individual game assets.
