ShowSplat help

Build a deck

Add slides from the toolbar or Templates menu. Use the slide rail to pick, duplicate, delete, and reorder slides.

Edit slide objects

Select a text box, image, media item, or table on the canvas. Drag to move it, use the corner handles to resize it, and adjust details in the Selection panel.

Use Markdown Studio

Open Insert > Markdown Studio for outline-first decks. Separate slides with three dashes. Headings become slide titles and bullets become editable list items.

Present

Use SlideShow to start from the first or current slide. Presenter controls include navigation, notes, timer, and a pop-out notes window.

Save and export

Save Local keeps an editable browser copy. Save JSON creates the durable editable file. Export WebDeck for a single-file audience version.

Import safely

WebDeck and JSON keep the most editability. PDF import preserves appearance as slide images. PPTX and ODP import common text, images, shapes, and backgrounds as best-effort editable slides.

Privacy

ShowSplat runs in the browser. Local saves stay in this browser profile unless you export or import a file. Frontend WebDeck passwords are a classroom convenience, not encryption.
