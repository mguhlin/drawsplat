Welcome to LayoutSplat

Select an object, drag it, or use the corner handle to resize it. Arrow keys move by 1 point; Shift moves by 10. Double-click a text frame to edit its whole story.

To link text, select a frame, choose Link frames, then select another frame. Continue on next page adds a connected frame for you.

Drag from either ruler to add a guide. Double-click a custom guide to remove it. Units and zoom change the view, not the document.

Print / Save as PDF opens your browser's print dialog. Choose Save as PDF, actual size, zero margins, and no headers or footers. Preview and print use the same pages.

Templates, master pages, mail merge, rich typography, local imports, and print preparation are available. Review the feature guide for format and print limits.

Work is saved in this browser when storage is available. Download a project to keep a portable copy. Bundled fonts and imported local fonts travel with saved projects.
