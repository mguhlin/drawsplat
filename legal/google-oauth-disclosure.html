    SplatWorks Google Access Disclosure

    Current deployment scope

    SplatWorks is the ecosystem; DrawSplat is the whiteboard. The ecosystem includes the five office apps, standalone creative and productivity tools, classroom widgets, and games. ConceptSplat, MarkdownSplat, DiagramSplat, QuizSplat, RubricSplat, and SketchSplat VR are current tool names; former names remain search aliases and existing URLs and project formats remain valid.

    Match this document to the components and services actually approved for your installation. Apps Script console controls apply to the DrawSplat whiteboard’s Drive/Sheets workflows; they do not automatically administer standalone app drafts or district MariaDB/MySQL records. See compliance and district review and the component data and network inventory.

    Updated October 15, 2026. Branding changes do not amend an existing signed agreement or expand the components, services, or data processing approved by a district. Templates and review packets are not executed agreements or compliance certifications.

    This public page identifies the SplatWorksTM ecosystem, including GridSplatTM, and explains why Google account, Drive, Sheets, Docs, and email-related permissions may be requested when a teacher, school, Hub administrator, or deployment owner connects SplatWorksTM tools to Google storage or protected admin workflows.

    App and Brand Identity

    Public access is available at splatworks.org and drawsplat.org. Existing OAuth app IDs and consent-screen labels may still say DrawSplat; verify the actual app, requested permissions, and approved origins. Branding changes do not grant additional permissions. DrawSplat Hub is the existing whiteboard administration workflow.

    What DrawSplat Does

    DrawSplatTM is an interactive browser whiteboard for classroom and visual work. Users can draw, add text, shapes, sticky notes, images, audio notes, graphs, templates, panels, and classroom widgets. Teachers can create classroom links, configure collaboration rooms, review turn-ins, use moderation tools, and optionally save classroom work through a Google Apps Script backend that writes to the teacher's or school's Google Drive and Google Sheets.

    GridSplatTM is a browser-based spreadsheet, charting, and pictograph tool in the SplatWorksTM ecosystem. It can work without sign-in and can optionally save native .gridsplat.json files to Google Drive when a deployment enables Google Drive cloud save and a user authorizes it. AudioSplat is a browser-based multitrack recorder and editor that can optionally upload a user-selected exported audio mix to the user's Google Drive and, only when requested, ask Drive to create an Anyone-with-the-link permission for sharing and a Drive-hosted preview embed.

    SplatWorksTM tools can also run without Google access in browser-only mode. Google access is used only when a teacher, Hub administrator, user, or deployment owner chooses a Google storage path or signs in for a protected admin workflow.

    Why Google Access Is Requested

    Google permissions are requested to provide teacher-controlled storage, user-authorized file save/open, classroom setup, and admin authorization. DrawSplatTM does not request Google access for advertising, profiling, selling user data, or unrelated analytics.

    How Google Data Is Used

    • Google account data is used to authenticate an admin session and enforce access rules for Hub or classroom setup pages.
    • Drive and Sheets data is used to store and retrieve DrawSplatTM classroom content, GridSplatTM save files when enabled, configuration, audit records, and teacher-managed workflow records.
    • Docs access is used to generate setup instructions for teachers added through DrawSplat Hub.
    • Email access is used only for deployment/admin notifications supported by the Apps Script backend.
    • DrawSplatTM does not sell Google user data, use it for ads, or transfer it to advertising networks.
    • Access is limited to the deployment workflows selected by the teacher, school, or Hub administrator.

    Storage, Control, and Removal

    For Google Apps Script deployments, the teacher, school, or Hub operator controls the Google account and Drive/Sheets files used by the deployment. DrawSplatTM stores classroom records in that operator-controlled Google environment, not in a separate DrawSplat-hosted database by default.

    For direct GridSplatTM and AudioSplat Google Drive save, files are stored in the authorizing user's Google Drive and access is limited to the narrow drive.file scope for files created or opened by the app. AudioSplat access tokens are kept in browser memory and audio is uploaded only after the user chooses Save to Google Drive.

    Administrators can remove teacher access from Hub Admin. The removal workflow deletes registry setup/admin/config entries for that teacher and attempts to remove the teacher's editor access from generated Drive folders and files. Deployment owners and users can also revoke app access in their Google Account security settings and delete DrawSplat-created or GridSplat-created files from Drive.

    Privacy Policy

    The full SplatWorks policy packet is available at https://drawsplat.org/legal/combined-policy. That URL should match the privacy policy URL entered in the Google OAuth consent screen configuration.
