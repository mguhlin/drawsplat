Teacher Quick Start

Options, Education Tools, and Teacher Admin access.

Use this short guide when you are setting up DrawSplatTM from the whiteboard before a full DrawSplat Hub account is ready.

Open Options

  1. Open DrawSplat Whiteboard.
  2. Click Options.
  3. Use the controls in the Options dialog to choose the workspace, view, and Teacher Admin setup path.

Turn On Education Tools

In Options → Workspace, choose Education Tools.

Education Tools reveals classroom-specific fields and controls, including class name, student name, teacher/student mode, assignment mode, teacher and student layers, answer key controls, turn-ins, moderation, collaboration rooms, and classroom-oriented templates or widgets.

Choose Simple or Advanced

In Options → View, choose the view that fits the lesson.

  • Simple keeps the interface focused on the core whiteboard tools.
  • Advanced shows the fuller toolkit, including templates, media tools, graphing, stickers, widgets, object controls, classroom extras, and additional import/export options.

Open Teacher Admin

  1. In the Options dialog, click Open Teacher Admin.
  2. Enter the temporary Teacher Admin password.
  3. If you do not have a Google Apps Script Web App URL yet, follow the Apps Script Web App URL setup tutorial.
  4. Paste your Google Apps Script Web App URL.
  5. Click Save URL, then Test Connection.
  6. Return to the whiteboard. This browser will remember your setup for Save to Google, Cloud Sync, templates, turn-ins, and classroom links.

Get the Teacher Admin Password

To request the temporary Teacher Admin password, use the Contact / Information Request form.

Include your name, school or organization, and a short note that you need the temporary Teacher Admin password for DrawSplat setup.
