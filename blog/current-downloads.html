What MySQL saving means today

Deploy an HTTPS API and database first, then connect it with Teacher Admin’s MySQL Wizard. Save online keeps private boards in the signed-in account, including added audio/video notes. Revision checks reject competing saves that would overwrite a newer copy.

Saving is explicit. Google classroom rooms, galleries, moderation, and turn-in/review remain separate; selecting MySQL does not enable those workflows or move existing data. Student accounts must be school-provisioned. Advanced district modules need separate validation. Read the hosting and connection guide.

Update with a backup

Keep board/project files and a database backup. Finish active recordings and exports before replacing files. Install matching package versions and retain your server’s private configuration. Verify downloads with SHA256SUMS-v3.1.31.txt; the older v3.1.25 release stays available unchanged.
