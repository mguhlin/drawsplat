GraphSplat · Mathematics

Equations you can use in your next lesson

Write a fraction, explain an algebra step, or prepare a statistics formula. GraphSplat's Equation Studio turns LaTeX notation into reusable artwork and structured MathML on your device.

Open Equation StudioWorkflow and examples

Start with an example

Open GraphSplat Examples and choose Fraction addition, Quadratic formula, Pythagorean theorem, Slope between two points, Mean of a data set, Definite integral, Aligned equation steps, or Matrix and vector. Edit the notation and description to fit your lesson.

Templates wrap selected text in fractions, roots, powers, and subscripts. Other buttons insert symbols, sums, integrals, matrices, and aligned steps. The examples supply authored explanations, rather than automatic solutions.

From notation to a classroom resource

  1. Choose Equation Studio, then type LaTeX or open an example.
  2. Edit the title, colors, and read-aloud description. Review the mathematical meaning.
  3. Download PNG or SVG for a worksheet, slide, or quiz. Copy LaTeX or MathML for a compatible editor.
  4. Keep Project JSON to continue editing later. Image exports are finished artwork.

Accessible MathML preview retains mathematical structure. Read description uses a supplied explanation and an available local browser voice; it does not interpret the equation. Verify the destination's accessibility and provide a reviewed description with an exported image.

Bring a table into your math materials

Open Table to LaTeX and paste spreadsheet cells or CSV data. Review the table preview, then copy booktabs source or download a complete LaTeX document. Science measurements, Coin-toss probability and Numeric matrix provide three editable examples. Numeric cells can become a matrix in Equation Studio. Project JSON keeps the table input and conversion settings.

Import and share LaTeX adds validated .tex equation imports, complete LaTeX documents, math-aware Markdown and self-contained HTML pages. HTML includes artwork and structured MathML without an external service. These local workflows were informed by StyleLaTeX. Photo, PDF and handwriting recognition, AI repair, and whole-document conversion are outside this feature.

A focused addition to the graph studio

The equation workspace complements the existing charts, coordinate planes, geometry, and function graphs. Use Expression calculator for functions, sliders, roots, and intersections.

The typed equation, template, source-copying, and graphics workflows were informed by TCEA's Equatio alternatives article. GraphSplat uses an independent local MathJax integration. Handwriting recognition, speech-to-math, predictive chemistry, automatic solving, and Google Workspace extensions are not included.

Reliability improvements across SplatWorks

The same release repairs storage-blocked startup and autosave recovery in office, video, classroom and admin tools. Bingo Caller now generates distinct column values, switches room subscriptions correctly, and keeps cleared marks after refresh. GraphSplat project files restore the correct workspace and reviewed descriptions.
