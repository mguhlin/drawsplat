October 9, 2026 · v3.1.30

More ways to finish your work

Today's updates make document conversion, photo editing, video bookmarks, audio checks, and presentation navigation easier to find and use. The matching self-host packages are refreshed too.

Get current downloadsOpen the tools

Open a file and make it a PDF

PDFSplat now accepts DOCX, PPTX, EPUB, Markdown, TXT, and browser-supported images alongside PDFs. Drop multiple files to combine their pages in order. Conversion happens on your device, and an unreadable file leaves the current document intact.

DOCX and EPUB text and embedded images reflow into PDF pages; PPTX slides become page images. Complex layouts, themes, charts, tables, and ebook styling may differ, so review the result. Linked images are not fetched. Old DOC/PPT files and encrypted ebooks need another conversion path. Converted files are limited to 50 MB each; batches accept up to 20 files totaling 100 MB.

Put your edits where you want them

Choose text, image, or signature, then click or tap its position on the page. Edit added text directly on the page with bold, italic, and left, center, or right alignment. Replacing extractable PDF text starts with its detected color, background, and closest font appearance. Custom fonts use the closest standard PDF font on export; mixed text styles and complex backgrounds may need adjustment.

Rotate a selected page without changing the others. Exports preserve each original page's rotation, including the reported page-two orientation issue. Save as now offers PNG, JPG, and WebP: one page downloads as an image; multiple pages download as numbered images in a ZIP. The existing selected-page PNG tool remains available.

Adjust a photo with confidence

In ImageSplat, select one image layer and choose Adjust photo. Brightness, contrast, saturation, and warmth controls include presets and a before/after preview. Cancel leaves it unchanged; Undo restores the original after Apply.

Bookmark moments in a video

VideoSplat adds named, colored timeline markers. Add one at the playhead, edit its label or time, click its ruler diamond, or move to the previous/next marker. Markers save with the project and do not alter exported footage.

Check a clip before changing it

In AudioSplat, choose Clip → Analyze audio for a whole clip or waveform selection. Duration, sample rate, channels, peak, RMS, DC offset, and full-scale sample counts help you inspect the audio. Analysis does not change samples and is not a LUFS or true-peak meter.

Find and present your slides

ShowSplat searches slide titles, content, tables, imported HTML, and notes. WebDeck v5 import/export includes notes, presenter previews and sync, notes sizing, close controls, mobile reflow, and print/PDF behavior. Canonical framework styles and complete footers are retained.

WebDeck v5 and clear action labels

ShowSplat uses the WebDeck v5 framework in self-contained HTML exports. A canonical deck with a linked framework stylesheet can import using the bundled styles. Multiple inline style blocks are preserved. Embed image/media assets or use resolvable URLs; importing a lone HTML file cannot supply its sibling files. Imported scripts are not executed, and custom scripted widgets may need review. Web fonts and external media still need internet.

Common actions across the Splat tools now use icons with visible labels. Existing native icons, keyboard shortcuts, undo history, and app-owned commands retain their roles.

Matching downloads

Release v3.1.30 refreshes thirteen core self-host packages, the standalone ClipSplat package, and the dedicated CipherSplat offline edition. ImageSplat is included in complete DrawSplat and Tools; ShowSplat is in the SplatWorks suite and its individual download. Extract complete ZIPs and keep shared dependencies and folder paths together.
