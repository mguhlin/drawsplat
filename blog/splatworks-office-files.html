SplatWorks: Office files and easier spreadsheet editing

Move classroom work between SplatWorks, Microsoft Office, and LibreOffice. WriteSplat reads and writes DOCX and ODT. ShowSplat exchanges PPTX and ODP. GridSplat now exchanges XLSX and ODS. ListSplat exchanges table records with Access and Base through CSV.

Select once, format together

Click a GridSplat row or column header, then apply bold, italic, alignment, colors, or a number format. Shift-click another header to select several. Use the reference box for a range such as A1:D10, A:C, or 2:5.

The Rows, columns & fill menu inserts or deletes rows and columns, fills formulas or number series, and replaces text in selected cells. Undo lets you step back. Unmerge cells before structural changes or filling.

The right app opens your file

Choose a recognized Office or SplatWorks project file in another suite app, and its matching app opens in a new tab with the file ready. Allow popups if asked. The file stays in your browser, and your existing saved projects stay in place. Save the imported project before closing its tab. This requires the matching app at the same website.

Keep the original

Conversions may change a document. GridSplat reads the first worksheet and supports common values, formulas, basic formatting, and merged cells. Advanced charts and macros may not carry over. ListSplat’s CSV exchange moves table records, not database forms, queries, or relationships.
