SplatWorks™

ShowSplat™ is the WebDeck-first presentation workspace.

Build slide decks with thumbnails, a central canvas, media anywhere on the slide, Markdown-first authoring, speaker notes, templates, themes, and single-file WebDeck HTML export.

Launch ShowSplat™ Development Plan

First release direction

Slides, media, Markdown, and WebDeck export.

ShowSplat starts with the core authoring loop and grows toward full ODP/PPTX export once the deck model stabilizes.

Author

Canvas editor

Use a slide thumbnail rail, central 16:9 canvas, notes panel, menus, toolbar icons, templates, themes, and draggable/resizable slide objects.

Insert

Media-rich slides

Insert text, bullet lists, tables, hyperlinks, PNG/JPG/GIF/SVG images, YouTube videos, MP4/WebM video, and audio.

Export

WebDeck output

Export one HTML file with slide data, speaker notes, progress, navigation, hash links, fullscreen, and optional frontend password prompt.
