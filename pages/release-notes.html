Release Notes

DrawSplatTM v3.1.8

Latest stable Self-host bundle refreshed Classroom tools update

DrawSplatTM v3.1.8 refreshes the self-host bundle with the latest classroom tools, Concept Map Studio upgrades, Quiz & Flashcard Studio science sample sets, and the DrawSplat Hub demo scaffold.

Download Self-Host Zip View Markdown Source

Highlights

What changed

SplatImage Studio

New browser-only image editor with resize, crop, masks, layer duplication, opacity, text alignment, proportional arrowheads, faster paste/import, and expanded visual effects.

DrawSplat Hub

New Hub dashboard scaffold with classroom-teacher, campus, and district grouping support plus a demo campus instance for self-hosters.

Concept Map Studio

Markdown import, text controls, dropdown menus, improved import collision layout, and cleaner selected-node editing.

Quiz & Flashcard Studio

Grade 3 Science TEKS, Grade 5 Science TEKS, and Grade 10 Biology TEKS sample data sets, plus clearer flashcard answer formatting.

Details

Included updates

  • SplatImage Studio now appears in the Tools dropdown as a standalone classroom image editor.
  • Crop handles, mask shapes, layer controls, and art effects were added or polished.
  • Large pasted screenshots show more quickly and oversized transparent or near-white margins are trimmed.
  • DrawSplat Hub includes the dashboard, the `hubcampus` demo instance, guided admin setup, optional Buy Me a Coffee support, and the Apps Script registry starter pattern.
  • Concept Map Studio adds Markdown import, improved controls, and cleaner generated/imported map placement.
  • Quiz & Flashcard Studio includes science sample sets and improved back-of-card answer clarity.
  • The bundled blog RSS snapshot was refreshed for self-hosted copies.

Self-Host Bundle

What the ZIP contains

The self-host ZIP is labeled drawsplat-selfhost-v3.1.8.zip. It includes the static site, Apps Script backend, MySQL backend, documentation, legal/compliance pages, standalone classroom tools, and the generic DrawSplat Hub dashboard with the hubcampus demo instance. Real Hub campus folders are intentionally excluded from self-host bundles.
