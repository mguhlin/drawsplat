Release Notes

DrawSplatTM v3.1.13

Latest stable ShowSplat starts Three self-host packages

DrawSplatTM v3.1.13 starts ShowSplatTM, the SplatWorksTM presentation and WebDeck authoring app, and expands separate self-host downloads to DrawSplatTM, GridSplatTM, and ShowSplatTM.

Download Self-Host Zips View Markdown Source

Highlights

What changed

ShowSplatTM

ShowSplatTM starts as a browser-native slide deck and WebDeck authoring app with thumbnails, canvas editing, media insertion, notes, templates, themes, Markdown Studio, and WebDeck export.

Active SplatWorksTM App

ShowSplatTM is now linked from SplatWorksTM menus and has a public page at pages/showsplat.html.

WebDeck Export

ShowSplatTM can export a single HTML deck with navigation, progress, notes, hash links, fullscreen controls, and optional frontend password prompt.

Markdown Workflow

A built-in Markdown Studio can build slides from an outline and export the current deck back to Markdown.

Bundle Script

The self-host bundle script now builds separate DrawSplatTM, GridSplatTM, and ShowSplatTM zips.

Details

Included updates

  • Added showsplat/ as a static SplatWorksTM presentation app.
  • Added showsplat/docs/plan.md with the long-term feature set and first implementation scope.
  • Added text, bullet list, table, hyperlink, image, YouTube, MP4/WebM, and audio insertion workflows.
  • Added draggable and resizable slide objects, speaker notes, slide templates, color themes, and browser autosave.
  • Added WebDeck HTML, Markdown, and browser print-to-PDF export paths. ODP and PPTX remain planned file writers.
  • scripts/make-selfhost-bundle.sh now creates splatworks-showsplat-selfhost-<version>.zip beside the DrawSplatTM and GridSplatTM zips.
