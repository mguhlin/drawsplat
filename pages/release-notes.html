Release Notes

DrawSplatTM v3.1.10

Latest stable Self-host bundle refreshed Classroom tools update

DrawSplatTM v3.1.10 refreshes the self-host bundle with Squirrel Run game polish, the current classroom tools, and the bundled blog RSS update snapshot.

Download Self-Host Zip View Markdown Source

Highlights

What changed

Squirrel Run Sounds

Movement now has light audio feedback, life loss has a splat sound, and the game header includes a classroom-friendly sound toggle.

Squirrel Remarks

When the squirrel gets stopped by traffic or hazards, a speech bubble pops up with a short squirrel-point-of-view joke.

Tree Celebration

Reaching the tree now triggers a brief celebratory dance before the next level starts.

Blog Snapshot

The bundled RSS feed includes the latest DrawSplat update posts so self-hosted copies render current news without external requests.

Details

Included updates

  • Squirrel Run now includes generated movement audio that plays only when the squirrel actually moves.
  • A splat sound plays when the squirrel loses a life, with a header sound toggle for quiet classrooms.
  • Collision feedback now includes a temporary speech bubble anchored near the place where the squirrel was stopped.
  • Goal feedback now pauses the level briefly and animates a small celebratory dance at the tree.
  • A phone-sized Playwright smoke test verified page load, start, touch movement, sound toggle, pause/resume, and no browser console/page errors.
  • The root Playwright package files are excluded from the self-host bundle while backend package files remain included.
  • The bundled blog RSS snapshot was refreshed for self-hosted copies.

Self-Host Bundle

What the ZIP contains

The self-host ZIP is labeled drawsplat-selfhost-v3.1.10.zip. It includes the static site, Apps Script backend, MySQL backend, documentation, legal/compliance pages, DrawSplat Games including Squirrel Run, standalone classroom tools, SplatImage Studio, SketchSpace VR, and the generic DrawSplat Hub dashboard with the hubcampus demo instance. Real Hub campus folders are intentionally excluded from self-host bundles.
