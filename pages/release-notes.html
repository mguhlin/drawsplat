Release Notes

DrawSplatTM v3.1.18

Latest stable Typing Games Markdown Studio SplatWorksTM hub

DrawSplatTM v3.1.18 refreshes the classroom-facing tools changed after the v3.1.17 audit release: Typing Games, Passage Coach, Markdown Studio, Tools and Widgets cards, and the SplatWorksTM hub page.

Download Self-Host Zips Modular self-host guide View Markdown Source

Classroom Tools

Typing, writing, cards, and SplatWorks

The release keeps the modular self-host package model and updates the surfaces teachers and students use directly.

Typing Games

The Typing Games area now includes Road Rally, Block Zap, and Passage Coach behind a shared game chooser.

Passage Coach

Teachers and students can import CSV, XLSX, JSON, or pasted text, practice localized passages, and continue automatically to the next passage.

Markdown Studio

Markdown Studio now imports HTML files, converts pasted HTML to Markdown, and exports WordPress block code.

Tools and Widgets

Tools and Widgets cards now show preview images, with screenshots replacing repeated generic icons for several cards.

SplatWorksTM

The SplatWorks hub now uses the new hero image, one-line headline, larger app icons, and launch buttons before the Apps section.

Typing Polish

Intermediate and expert typing modes use longer words, Road Rally collision behavior is fairer, and typing-game vehicles and audio were refined.

Navigation

Language switching and page menus were kept visible across the updated DrawSplat tool and game surfaces.

Checksums

The release includes SHA256SUMS-v3.1.18.txt for verifying all ZIP downloads.

The package model remains additive: unzip modules into the same web root and keep folder names unchanged. No installer or server-side linking step is required.

Highlights

What changed

Custom Typing Practice

Passage Coach accepts teacher-created or student-provided material and tracks continued typing performance across passages.

Localized Passages

Passage Coach now swaps passage content with the active language instead of leaving the practice screen in English.

Import and Export

Markdown Studio supports HTML import/paste workflows and WordPress block-code output for classroom publishing.

Visual Browsing

Tools, Widgets, and Games pages are easier to scan because cards now show the actual app or game look alongside titles and descriptions.

Hero Refresh

The SplatWorks hub now leads with a compact classroom-office-suite hero image and launch buttons above the Apps section.

Details

Included updates

  • Updated Typing Games with Road Rally, Block Zap, Passage Coach, language switching, longer intermediate/expert words, and better Road Rally jump/collision behavior.
  • Updated Passage Coach with import workflows, localized practice passages, auto-advance after completion, and continuous performance tracking.
  • Updated Markdown Studio with HTML file import, pasted HTML conversion, HTML-to-Markdown conversion, WordPress block-code export, and cleaner examples.
  • Updated Tools and Widgets cards with images and screenshot thumbnails for repeated-card cases.
  • Updated SplatWorks hub layout, hero image, launch buttons, and icon sizing.
  • Rebuilt all nine self-host ZIP packages and the release checksum file.

Self-Host Bundles

What the ZIP files contain

drawsplat-selfhost-v3.1.18.zip, the SplatWorksTM suite and app ZIPs, and the DrawSplatTM Tools, Widgets, and Games module ZIPs are attached to the GitHub release. SHA-256 values are listed in SHA256SUMS-v3.1.18.txt. Real Hub campus folders are intentionally excluded from self-host bundles.
