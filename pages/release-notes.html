Release Notes

DrawSplatTM v3.1.11

Latest stable Self-host bundle refreshed DrawSplat Studio update

DrawSplatTM v3.1.11 brings GridSplatTM into DrawSplat Studio, refreshes Studio navigation around SplatWorksTM, and rebuilds the self-host bundle with the integrated spreadsheet app.

Download Self-Host Zip View Markdown Source

Highlights

What changed

GridSplatTM

The spreadsheet app is now part of DrawSplat Studio and ships with built static assets for Cloudflare Pages and self-hosted sites.

SplatWorksTM

Studio suite language now centers on SplatWorksTM, WriteSplatTM, ListSplatTM, ShowSplatTM, and GridSplatTM.

Studio Dropdown

The top navigation now uses one Studio menu with SplatWorksTM, Tools, Widgets, and Games groups for quick access.

Collection Pages

Dedicated Games and Tools pages let visitors browse each collection as a full page instead of only through dropdown links.

SplatWorksTM Tools

Big Link, Concept Map, Markdown Studio, Rubric Builder, SplatImage Studio, and Word Search Maker now sit under SplatWorksTM.

Details

Included updates

  • GridSplatTM now lives at gridsplat/ as part of this repository and loads from the production Vite bundle.
  • A dedicated GridSplatTM page introduces it as the SplatWorksTM spreadsheet for classroom tables, charts, and data work.
  • The Studio dropdown includes SplatWorksTM, Tools, Widgets, and Games groups across the public navigation pages.
  • SplatWorksTM is described as kid-friendly tools for writing, data, and classroom projects.
  • Planned Studio app names now use WriteSplatTM, ListSplatTM, and ShowSplatTM for writing, data, and outline-to-slides presentations.
  • Tools and Games each have a dedicated collection page for browsing everything in that category.
  • The self-host bundle builder now includes games/ and gridsplat/ in its embedded deployment notes.

Self-Host Bundle

What the ZIP contains

The self-host ZIP is labeled drawsplat-selfhost-v3.1.11.zip. It includes the static site, Apps Script backend, MySQL backend, documentation, legal/compliance pages, DrawSplat Games, standalone classroom tools, the integrated GridSplatTM app, SplatImage Studio, SketchSpace VR, and the generic DrawSplat Hub dashboard with the hubcampus demo instance. Real Hub campus folders are intentionally excluded from self-host bundles.
