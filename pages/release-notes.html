Release Notes

DrawSplatTM v3.1.17

Latest stable Whiteboard polish Concept Map Studio Desktop/mobile audit

DrawSplatTM v3.1.17 is a whole-universe cleanup release. It tightens the DrawSplat whiteboard, makes Concept Map Studio easier to edit directly on screen, cleans up mobile and public-page edges, fixes Hub/admin sign-in behavior, and refreshes every self-host ZIP package.

Download Self-Host Zips Modular self-host guide View Markdown Source

Audit Refresh

Whiteboard, tools, pages, and packages

The release keeps the modular self-host package model and updates the working surfaces that teachers and students touch most often.

Whiteboard Shell

CSP/version stamp fixes, responsive layout polish, onboarding sequencing, refreshed offline cache behavior, and repaired Concept Map launch handling.

Concept Map Studio

Bubble labels edit directly on click, bubble widths resize with handles, the canvas scrolls internally, and the opening chooser now offers templates.

Cleaner Controls

Concept Map Studio adds a simple top action bar and selected-bubble contextual controls for faster editing without digging through menus.

Public Pages

Download, legal, support, language, and community pages were cleaned for mobile wrapping, overflow, CSP, and local-preview sign-in behavior.

Hub and Admin

Hub/admin pages received OAuth/CSP fixes, local sign-in guards, and mobile launch layout cleanup.

SplatWorksTM

Static development-template fallbacks now explain the right app entry point instead of presenting blank or broken template pages.

Tools, Widgets, Games

Standalone tools, widgets, and game entry points were checked as part of the desktop/mobile audit pass.

Checksums

The release includes SHA256SUMS-v3.1.17.txt for verifying all ZIP downloads.

The package model remains additive: unzip modules into the same web root and keep folder names unchanged. No installer or server-side linking step is required.

Highlights

What changed

Direct Bubble Editing

Concept Map bubble labels now edit in place by clicking the label, matching the direct connector-label workflow.

Resizable Bubbles

Selected Concept Map bubbles expose width handles, so teachers and students can shape individual nodes visually.

Scrollable Canvas

Concept Map Studio now keeps large maps inside an internal scroll area instead of forcing the whole page to carry the canvas.

Template Start

The new start dialog lets users begin with a blank map or choose a visual template such as process, circle, flow, site map, or tree layouts.

Audit Coverage

Public pages, Hub/admin surfaces, language whiteboards, SplatWorks entries, tools, widgets, games, and static HTML routes were checked at desktop and mobile sizes.

Details

Included updates

  • Updated DrawSplat whiteboard shell behavior, responsive layout, onboarding notices, offline cache behavior, and Concept Map launch behavior.
  • Updated Concept Map Studio editing, resizing, scrolling, start-template, toolbar, and contextual bubble controls.
  • Fixed public-page mobile wrapping, language config loading, community local-preview sign-in behavior, and Hub/admin OAuth/CSP issues.
  • Added static fallbacks for SplatWorks development-template pages.
  • Rebuilt all nine self-host ZIP packages and the release checksum file.

Self-Host Bundles

What the ZIP files contain

drawsplat-selfhost-v3.1.17.zip, the SplatWorksTM suite and app ZIPs, and the DrawSplatTM Tools, Widgets, and Games module ZIPs are attached to the GitHub release. SHA-256 values are listed in SHA256SUMS-v3.1.17.txt. Real Hub campus folders are intentionally excluded from self-host bundles.
