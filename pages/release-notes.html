Release Notes

DrawSplatTM v3.1.14

Latest stable SplatWorks folder ShowSplat editor

DrawSplatTM v3.1.14 organizes GridSplatTM and ShowSplatTM under the new splatworks/ folder, adds a SplatWorksTM hub page, and expands the ShowSplatTM editor with child-friendly object controls, richer thumbnails, templates, audio, and JSON save/load workflows. Current live updates after the tag add ShowSplatTM PDF, ODP, PPTX, and editor workflow refinements.

Current Live Updates

ShowSplat updates after v3.1.14

These changes are live on main and the public site, but they are newer than the v3.1.14 ZIP artifacts.

Import and Export Menus

File menus now group WebDeck HTML, Markdown, PDF, ODP, and PowerPoint/PPTX import/export actions under clearer submenus.

PPTX and ODP Compatibility

PowerPoint and ODP import/export are available as best-effort conversions for text, images, backgrounds, many shapes, and common grouped content.

PDF Workflows

PDF import creates full-slide image pages, including password-protected PDFs after a prompt. PDF export uses the browser print dialog and Save as PDF.

Editing Controls

Selected text boxes can toggle bullets, shrink or grow font size, and use the zoom slider. Deleting the final slide now creates a blank title slide.

Presentation Mode

Presenter navigation auto-hides after a few seconds and returns on hover. Notes can pop out into a movable window for a second display.

Known next-run focus: improve PPTX/ODP fidelity, add editable PDF text extraction, move large imported assets to IndexedDB, add a direct deterministic PDF writer, improve table-cell editing, and add fixture-based import regression tests.

Highlights

What changed

SplatWorksTM Folder

GridSplatTM and ShowSplatTM now live under splatworks/, matching the app routes and self-host bundle structure.

SplatWorksTM Hub

The new hub page outlines GridSplatTM, ShowSplatTM, and planned WriteSplatTM and ListSplatTM tools with launch buttons and icons.

ShowSplatTM Controls

ShowSplatTM now has richer thumbnails, four-corner resize handles, rotation, no-scroll text boxes, text fit/autofit, and image crop mode.

Audio and Data Templates

New templates support purple presentation slides, graphs from SplatWorks/DrawSplat tools, concept maps, slide audio, deck-wide soundtrack audio, and JSON deck files.

Legal Links

SplatWorksTM pages and ShowSplatTM Help now link to Terms/Privacy and GDPR, and license language covers both GridSplatTM and ShowSplatTM.

Details

Included updates

  • Moved GridSplatTM and ShowSplatTM into splatworks/ and updated public app launch paths.
  • Added pages/splatworks.html as the SplatWorksTM hub.
  • Added ShowSplatTM purple templates, graph/concept-map templates, slide audio, deck soundtrack audio, and JSON save/load labeling.
  • Added ShowSplatTM miniature slide previews, no-scroll text boxes, child-friendly inspector text, four-corner resize handles, rotate handle, fit/autofit text, and image crop mode.
  • Updated SplatWorksTM privacy/terms links and license copy.
