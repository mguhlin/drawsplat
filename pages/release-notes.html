Release Notes

DrawSplatTM v3.1.9

Latest stable Self-host bundle refreshed Classroom tools update

DrawSplatTM v3.1.9 refreshes the self-host bundle with SketchSpace VR, the latest SplatImage Studio cutout and text upgrades, current classroom tools, and the bundled blog RSS update snapshot.

Download Self-Host Zip View Markdown Source

Highlights

What changed

SketchSpace VR

New paper-first virtual room tool with printable 4x3 template, crop preview, room viewer, curriculum starters, Play examples, and a Teacher Guide.

SplatImage Studio

Richer text insertion, Canva-friendly clipboard image workflows, selected-object copy/export, Smart background cutout, Remove edge background, and a visible Working dialog during longer cutout tasks.

Teacher Materials

SketchSpace VR now includes lesson ideas, assessment prompts, image prompt patterns, six starter layouts, and full-screen links for starter examples.

Blog Snapshot

The bundled RSS feed includes the latest DrawSplat update posts so self-hosted copies render current news without external requests.

Details

Included updates

  • SketchSpace VR now appears in the Tools dropdown as a standalone classroom solution.
  • The SketchSpace VR student tool includes the printable room template, crop preview, trim controls, starter layouts, split-view, fullscreen viewing, and phone viewer mode.
  • The Teacher Guide includes setup steps, lesson ideas, assessment prompts, image prompt patterns, starter layout links, and cited inspiration articles by title.
  • The Play page shows example rooms and links the new examples and workflow visuals full screen.
  • SplatImage Studio supports richer text boxes with font size, bold, italic, underline, alignment, and preview.
  • SplatImage Studio includes Smart background cutout and Remove edge background with non-AI interface language and a visible Working dialog during longer processing.
  • Clipboard image workflows and selected-object PNG export are documented in the current bundle.
  • The bundled blog RSS snapshot was refreshed for self-hosted copies.

Self-Host Bundle

What the ZIP contains

The self-host ZIP is labeled drawsplat-selfhost-v3.1.9.zip. It includes the static site, Apps Script backend, MySQL backend, documentation, legal/compliance pages, standalone classroom tools, SplatImage Studio, SketchSpace VR, and the generic DrawSplat Hub dashboard with the hubcampus demo instance. Real Hub campus folders are intentionally excluded from self-host bundles.
