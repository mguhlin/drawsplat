Release Notes

DrawSplatTM v3.1.12

Latest stable Separate self-host packages SplatWorks download split

DrawSplatTM v3.1.12 separates self-host download artifacts for DrawSplatTM and SplatWorksTM GridSplatTM while keeping them listed together on the same public download page.

Download Self-Host Zips View Markdown Source

Highlights

What changed

DrawSplatTM Package

The DrawSplatTM zip now carries the whiteboard, tools, widgets, games, backends, and legal/compliance docs without bundling GridSplatTM.

GridSplatTM Package

The SplatWorksTM GridSplatTM zip carries the GPL-3.0-only spreadsheet app, built static assets, source, docs, tests, and license files.

Independent Updates

Future GridSplatTM updates can ship without forcing schools to redownload the full DrawSplatTM package.

Download Page

The download page now shows both packages together with separate versions, sizes, hashes, licenses, and deployment notes.

Bundle Script

The self-host bundle script now builds both zips in one run and excludes local development artifacts from release packages.

Details

Included updates

  • scripts/make-selfhost-bundle.sh now creates drawsplat-selfhost-<version>.zip and splatworks-gridsplat-selfhost-<version>.zip.
  • The DrawSplatTM zip excludes gridsplat/ so the whiteboard/tools/widgets/games package can move independently.
  • The SplatWorksTM GridSplatTM zip preserves the gridsplat/ folder because the current production build runs at /gridsplat/.
  • The package READMEs document the deployment path and licensing boundary inside each zip.
  • Local development folders such as node_modules, dist, coverage, and test artifacts are excluded from release packages.
