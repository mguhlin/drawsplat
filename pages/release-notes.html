    Clear offline choices and root shortcuts

    PDFSplat now opens directly from its extracted HTML in tested desktop Chrome and Firefox. CipherSplat’s offline ZIP includes its shared resources. Every package includes START-HERE.html and local launchers for Windows, macOS, and Linux; install Python 3 before going offline. Root-level OPEN-APP.html and named app shortcuts lead to the right app or its launcher instructions. Each individual app download states its offline requirements, and CipherSplat has its own download card.

    September 23 live tool updates

    Touch PDF signing, tab/window capture to PDF, GPU-assisted English captions, and accelerated VideoSplat export are now live. These features and the September 24 VideoSplat recording fixes are included in all applicable v3.1.31 packages. Read the feature walkthrough.

    October 11, 2026 · Support wiki and refreshed packages

    The DrawSplat Wiki brings installation, teacher guides, database setup, Apps Script, licensing, pricing, OAuth, and NDPA/DPA review into a searchable sidebar reference. MySQL/MariaDB and Compliance Console documentation now distinguish district classroom records from Apps Script controls. Inactive Community Board navigation is hidden. District suite v1.2.2 and static bundles v3.1.33 include the refreshed documentation.

    The full whiteboard, classroom modules, SplatWorks apps, and independent media tools now ship from the latest source. All thirteen ZIPs have fresh SHA-256 checksums.

    Typing Games: four independent adventures

    Cipher Chase adds TEKS definitions and a sound test. Wordfall Reactor defaults to everyday words against a computer, with optional TEKS sets and definition-only hints. Story Sprint blocks pasted answers while keeping classroom imports. Paws & Keys Adventure adds 12 kitten-and-puppy trails for ages 4–9. All four include instructions and language options.

    Choose a game · Read the walkthrough. The full DrawSplat and Games v3.1.31 ZIPs include these games and their shared assets. For local use, extract the whole ZIP and use the included Python 3 launcher.

    A friendlier whiteboard

    Illustrated menus explain each action. Teacher/student views, clearer everyday controls, simpler coloring, chemistry stamps, and lesson starter layouts help students get started.

    Finish voice and video notes

    Play, pause, and stop notes, review recordings before adding them, and recover stopped drafts after a refresh on the same device, normally for 24 hours. Teachers choose whether students can record short video notes.

    Your choice of MySQL host

    Private Save/Open uses the same Node.js API on Railway, DigitalOcean, or an existing MySQL 8 server. Database credentials stay on the server. The setup wizard tests compatibility before enabling saving.

    Updated creative tools

    The applicable packages include recent PDF camera/photo scanning and export improvements, image and video green-screen workflows, and media recording/export fixes. Automatic English captions and export progress remain included.

    VideoSplat recording fixes

    Encoded WebM timestamps determine clip duration even when browser metadata reports a short fragment. Recording review warns about incomplete video and offers the original download. File → Download original media retrieves stored footage without timeline edits. Video imports over 512 MB use bounded-memory hashing.

    Pick the package you need

    Choose the full DrawSplat download for the static whiteboard, tools, backends, and documentation. Add the SplatWorks suite or individual GridSplat, ShowSplat, WriteSplat, and ListSplat packages separately. Tools, Widgets, and Games are drop-in modules; AudioSplat, VideoSplat, MediaSplat, and PDFSplat also have independent downloads.

    The release/package version is v3.1.31; the included whiteboard reports its own version, v3.1.12. Individual downloads contain their applicable apps and shared files, rather than another copy of the full whiteboard/backend.

    What MySQL saving means today

    Deploy an HTTPS API and database first, then connect it with Teacher Admin’s MySQL Wizard. Save online keeps private boards in the signed-in account, including added audio/video notes. Revision checks reject competing saves that would overwrite a newer copy.

    Saving is explicit. Google classroom rooms, galleries, moderation, and turn-in/review remain separate; selecting MySQL does not enable those workflows or move existing data. Student accounts must be school-provisioned. Advanced district modules need separate validation. Read the hosting and connection guide.

    Update with a backup

    Keep board/project files and a database backup. Finish active recordings and exports before replacing files. Install matching package versions and retain your server’s private configuration. Verify downloads with SHA256SUMS-v3.1.31.txt; the older v3.1.25 release stays available unchanged.

    October 9 creative-tool updates

    PDFSplat converts supported documents and images locally, places text and signatures where you click or tap, edits text on the page, preserves page orientation, and saves PNG, JPG, or WebP. ImageSplat adds reversible photo adjustments, VideoSplat adds timeline markers, AudioSplat adds clip and selection analysis, and ShowSplat imports and exports WebDeck v5 with searchable slide navigation. Action icons keep visible labels.

    Complex Office and ebook layouts may differ after conversion. The current packages include these changes and their shared dependencies. Read the walkthrough and limits · Release notes.

    New in v3.1.31: PDF presentations

    Present edited PDF pages in a separate viewer, request full screen, blank the display, or run timed slides with optional looping. Save as WebDeck v5 creates a portable offline HTML presentation compatible with ShowSplat. These features are included in the refreshed PDFSplat, Tools, and full downloads. Read the classroom walkthrough and ELE alignments.
