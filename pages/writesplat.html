SplatWorks™

WriteSplat™ is the classroom writing workspace.

WriteSplat™ is a private, browser-based word processor for drafts, classroom handouts, readability feedback, templates, cloze passages, citations, and portable document exports.

Launch WriteSplat™

Current app

Write, analyze, save, and export without an account.

WriteSplat gives teachers and students a simple writing space with automatic saving, easy file backup, readability feedback, ready-to-use classroom templates, teacher-friendly writing tools, and export options for sharing or printing student work.

Write

Document canvas

Use a clean editable page with SplatWorks menus, icon-first toolbar, style controls, browser spellcheck, print path, light/dark mode, and responsive sidebar drawer.

Save

Portable document state

Autosave stays local to the browser. Durable work can use a `.writesplat.json` file, while OpenDocument `.odt` import and export supports classroom workflows in LibreOffice.

Analyze

Readability cards

The sidebar shows grade target, expandable stats, reading time, and color-coded suggestions for hard sentences, passive voice, adverbs, simpler alternatives, and weak phrases.

Teach

Educator workflows

Teacher tools include templates, cloze builder, citation assistant, teacher/student view, answer keys, vocabulary highlights, sentence scramblers, and student/teacher exports.
