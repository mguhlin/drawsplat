    Feature Set

    DrawSplatTM is a visual whiteboard with classroom-ready creation tools.

    Use the core whiteboard for drawing, notes, media, and panels, then open focused builders for ScratchArt, charts, picture graphs, diagrams, dot art, stickers, collages, and classroom setup workflows.

    Menus at a Glance

    What you can insert and which workflows live in Tools

    The Insert menu is for content added to the board. The Tools menu is for classroom workflows, generators, background utilities, reusable frame actions, and new-tab classroom activity widgets.

    Insert

    Content added to the board

    • Load Image
    • Coloring Book
    • Mosaic Images and Collage
    • Graph Creator and Picture Graph
    • Mermaid Diagram, Word Cloud, and Concept Map
    • Emoji Mixer
    • ScratchArt
    • Dot Pictures
    • Stickers and Custom Sticker
    Tools

    Workflows and utilities

    • Save Current Frame as Reusable Template
    • Open Reusable Frame Templates
    • TNT Reset (with dramatic detonation sound)
    • Sidebar Undo / Redo / Audio On-Off toggle

    Open Directly

    Standalone classroom widgets

    These classroom tools run as their own pages, so you can use them without first opening the DrawSplatTM whiteboard.

    AudioSplat

    Record from a microphone, import audio, arrange clips on multiple tracks, edit non-destructively, save local projects, and export a WAV mix. Audio stays in the browser unless you download it.

     Animated GIF Maker

    Build an animated GIF from image frames. Reorder, set per-frame delay, loop count, original-resolution or scaled output. Per-frame median-cut palette with optional Floyd-Steinberg dithering for clean gradients. Real LZW compression and adjustable palette size (256 → 32 colors) typically produce GIFs under 100 KB. Also exports as MP4 video (modern browsers, via native WebCodecs) or WebM. Everything runs in the browser; nothing is uploaded.

     Big Link

    Make a poster-style "type this URL" card to project on the board or print as a sign. Big bold link, optional title strip, optional note, accent color, four card shapes (16:9 / 4:3 / 1:1 / 3:4). Download as PNG or SVG. Standalone version of the whiteboard's Big Link widget.

     Bingo Card Generator

    Create printable bingo cards from vocabulary, questions, names, or numbers.

     Live Bingo Caller

    Run animated bingo calls and same-device player cards.

     Brain Sort

    Dump every thought in your head and get back a grouped, checkable to-do list — by topic, effort, or when.

     Clock Wizard

    Get an honest time estimate for a task, with phase breakdown and an ADHD-tax allowance so you don't over-promise.

     Markdown Studio

    Write, preview, and export classroom Markdown pages.

     Mermaid Diagram Studio

    Compose flowcharts, sequence diagrams, mind maps, Gantt, timelines, class, state, and Venn diagrams. Live preview and export.

     Chart Studio

    Turn a CSV into a bar chart, line chart, or animated bar-chart race. Pick columns, choose a palette, download PNG or SVG. Runs entirely in the browser.

     CipherSplat

    Protect files, recursive folders, and private text with local AES-256-GCM encryption. Nothing is uploaded, tracked, or stored by DrawSplat.

     Coloring Book

    Color printable line-art pages right in the browser — pick a page, paint with a brush and color palette, undo or clear, then download PNG/SVG or print.

     Graph Maker

    Draw a Cartesian coordinate plane, plot points, connect them, and add a y = mx + b line. One- or four-quadrant grids for math lessons. Download PNG or SVG.

     Picture Graph

    Build a pictograph where one icon equals a set number of units. Editable rows, emoji icons, adjustable key, optional values. Download PNG or SVG.

     Coin Flipper

    Flip custom coins for probability, games, and quick choices.

     Concept Map Studio

    Infinite canvas with drag, zoom, and Space+drag pan. Word-wrapped labels in three size tiers (main idea / connected / detail). Twelve graphic-organizer templates. Optional section filter and a live traditional outline view (Roman/Letter/Number) you can copy as Markdown or hand off to Markdown Studio. Save/load JSON, export readable SVG/PNG, or copy an <iframe> embed code for Google Sites and WordPress. JSON Schema spec for AI-generated maps.

     Dice Roller

    Roll classroom dice for games, math, and random prompts.

     Dicebreaker Creator

    Create dice-based discussion prompts and icebreakers.

     Draw & Sketch

    Quick freehand sketch pad for warm-ups and visual brainstorming.

     Fortune Wheel

    Teacher-curated wheel with a student-facing share link.

     Meme Puzzle

    Build image-based puzzle activities for students.

     Quiz & Flashcard Studio

    Build or import quiz question banks from CSV, JSON, XLSX, ODS, or ODT; run student/team quiz links; export question banks; and transfer the same content into printable flashcards. Includes drawsplat-quiz-flashcard_v1 CSV/JSON templates for AI-generated imports.

     Rubric Builder

    Create practical rubrics for projects and assignments.

     ImageSplat™

    Edit screenshots and images with Lightshot-style annotations, Kleki-inspired layers, crop, arrows, boxes, text, clipboard import/export, selected-image GIF creation, and frame downloads for the DrawSplat Animated GIF Maker. Runs entirely in the browser.

     Step-Splat

    Splat any task into bite-size steps with adjustable spiciness — a neurodivergent-friendly task chunker.

     Story Wheel

    Spin story prompts for writing, speaking, and warmups.

     Toneshifter

    Paste a draft and rewrite it in a chosen tone — formal, friendly, concise, diplomatic, encouraging, or plain English.

     Vibe Check

    Paste a tricky message and get an honest read on its tone — warm, urgent, sarcastic, frustrated, passive-aggressive, and more.

     Wheel Spinner

    Generic spinner — drop in any list and let the wheel pick the winner.

     Word Search Maker

    Generate word searches for vocabulary practice.

    Self-Hosting Security

    Hardened backend controls for district deployments

    DrawSplatTM v3.1.7 refreshes the self-hosted MySQL path with practical guardrails for schools and organizations running their own backend. The self-host bundle also includes browser-only classroom widgets such as Quiz & Flashcard Studio and its versioned CSV/JSON import templates.

    Backend

    Safer API defaults

    • Security headers and disabled Express fingerprinting
    • Configurable CORS allowlist for production domains
    • API, auth, OAuth, and parent-request rate limits
    • Generic client-facing server errors to avoid leaking database details
    Admin

    Controlled bootstrap and maintenance

    • Public registration can no longer self-assign admin roles by default
    • First-admin bootstrap requires explicit environment variables
    • Maintenance cleanup requires a token or district/campus admin session
    • SSE board subscriptions are validated and capped per connection
    Content

    Input and preview hardening

    • Room keys are limited to short URL-safe IDs
    • Board and template JSON payloads have configurable size caps
    • Markdown Studio blocks dangerous link/image schemes in preview
    • Generated Markdown attributes are escaped before insertion

    Play Together

    DrawSplatTM Games

    Standalone classroom games — turn-based, multiplayer, or single-player puzzles that open in their own page. More games are on the way; check the Games dropdown in the top nav for the latest list.

    Castles & Catapults

    Pixel-art two-player castle siege — choose munitions, account for wind, and topple the opposing keep.

     Dots and Boxes

    Two-player classic — connect dots to claim boxes on a colourful grid. Pick CPU or pass-and-play.

     Flood Fill

    Colour-merging strategy — flood from the top-left and unify the whole board within a move budget.

     Flow Free

    Connect every matched terminal pair with non-crossing paths. Cover every cell to win.

     Fun Quiz

    Pick a quiz pack (Winnie the Pooh, Smurfs, Snow White, Looney Tunes) and play a quick character-trivia round.

     GilaSplat

    Retro underground maze arcade. Guide a purple iridescent gila monster through 15 hand-illustrated desert burrows, eating eggs and hatchlings while dodging foxes, owls, hawks, and coyotes — with spoken quips on every snack.

     Lights Out

    Matrix-inversion puzzle. Toggle cells (and their orthogonal neighbours) to clear the grid under par.

     Splatball

    Colorful paddle-rally arcade with sound. Player vs Player, Player vs Computer, or Computer vs Computer — pick names, colors, and a target score.

     Squirrel Run

    Cross three traffic lanes, dodge vehicles and animals, collect acorns, and guide the squirrel safely to the tree hollow.

     Super Star Trek

    Command the Enterprise in a browser edition of the classic quadrant strategy game with sensors, shields, phasers, torpedoes, starbases, and a mission clock.

     Tangram Packing

    Drag and rotate polyomino blocks to fill a dark silhouette without overlap.

     Typing Games

    Four separate experiences: spy driving, a computer word-board opponent, passage practice, and a kitten-and-puppy adventure for ages 4–9. Each has instructions and six interface languages.

     Cipher Chase

    Type TEKS vocabulary to clear rival cars, steer around civilians, and learn each word’s definition. Sound starts on and includes a playback test.

     Wordfall Reactor

    Connect letters on a word board against the computer. Starts with 95 everyday words; TEKS science, math, and social studies vocabulary is optional. Hints give definitions, leaving you to find the word and its placement.

     Story Sprint

    Type passages with speed, accuracy, and character feedback. Import classroom text locally; paste and drag/drop are blocked in scored practice. Choose Next passage when you finish.

     Paws & Keys Adventure

    Meet kittens and puppies in a gentle adventure for ages 4–9, with 12 progressive trails, four worlds, finger hints, and saved stars.

     Untangle

    Drag graph nodes around until no edges cross. Crimson lines fade to emerald as you clear them.

    Graph Creator

    Create bar, line, area, and pie charts from quick classroom rows. Use it for surveys, counts, comparisons, and discussion prompts.

    Picture Graph

    Build picture-first graphs where students can work from icons, uploaded images, and locally bundled Smithsonian Open Access animal photos.

    Mermaid Diagrams

    Generate flowcharts, sequences, mind maps, timelines, Gantt charts, class diagrams, and state diagrams from Mermaid syntax.

    Concept Maps

    Create concept maps directly on the canvas with editable nodes, live connectors, node images, and Ctrl/Cmd-click web links.

    Dot Pictures

    Insert dot-based hearts, flowers, rockets, butterflies, apples, ten frames, fish, suns, boats, and more for math and pattern work.

    Sticker Library

    Use quick visual stamps for feedback, signals, prompts, sorting, and student-friendly board markup.

    Collage

    Select images on the board and combine them into layouts with optional titles, banners, background color, and accent color.

    ScratchArt

    Add a ScratchArt cover over a colorful background, then use circle-size Eraser controls to reveal the hidden layer. Each reveal stroke can be undone incrementally.

    Panel Background Templates

    Use original DrawSplatTM classroom backgrounds as locked panel structures for organizers, literacy, math, science, stations, and reflection.
