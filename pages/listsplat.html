    SplatWorks™

    ListSplat™ is the classroom database workspace.

    ListSplat™ helps students collect, organize, search, sort, and share structured information using child-friendly tables, forms, cards, labels, reports, CSV files, and native project files.

    Launch ListSplat™

    Current app

    Build a simple database without an account or server.

    ListSplat v0.2.0 includes 15 classroom starters with 12 records in every table, connected-table examples, validated primary/foreign keys, Markdown imports, lookups, reports, and teacher-guided database projects.

    Collect

    Tables, fields, and records

    Create fields, enter records, choose field types, add notes, and save the whole project locally or as a `.listsplat.json` file.

    View

    Forms, cards, labels, and reports

    Switch between table, form, card, gallery, label, and report views so students can see the same data in different useful formats.

    Search

    Find, sort, and clean data

    Use quick search, field-specific search, sorting, missing-value checks, duplicate checks, and replace tools for real database habits.

    Teach

    Classroom templates

    Choose 15 starters, each with 12 records per table: reading, science, geography, vocabulary, surveys, exhibits, weather, gardening, budgeting, classroom jobs, and makerspace supplies. Library Books & Loans and Investigations & Trials include working relationships.

    Connect tables with classroom examples

    Load Library Books & Loans to explore a book ID referenced by several loans, or Investigations & Trials to compare repeated measurements. Every table has 12 records. Click Keys & Relationships for a field diagram and an example using the currently selected tables. Primary keys must be unique and nonempty; new links validate foreign keys and block edits/deletions that would leave a child without its parent. One-to-one links require unique foreign keys.

    Choose parent records by name while storing their IDs. The arrow opens the linked record. Closing a table tab preserves its data; Reopen table brings it back. Dialogs have top-right close buttons.

    People, books and measurements in starters are fictional practice data. Verify factual claims and add sources before a research report. Read the classroom walkthrough.

    Getting started

    Choose a template or create a project. Define fields, add a few records, and try table and form views. Search or sort the records, then save a .listsplat.json project backup. Use File → Import Markdown table to paste a table or choose a .md file, select a table from the document, preview columns, and import as a new table or append records. CSV/TSV exchange remains available.

    Saving and school hosting

    Browser storage belongs to this browser and device; it is not a durable backup. Save project files regularly and test reopening them. Installing the district suite makes the app available on your school server; it does not automatically connect every SplatWorks file to whiteboard account-based saving.

    SplatWorks overview and installation · Licensing · Download packages

    Exchange table records with Access and Base

    Import and export CSV table records. Export a table as CSV from Access or Base, then use File → Import CSV in ListSplat and review the field mapping. To send records back, export a ListSplat table as CSV and use the other app’s text import tool. Transfer each table separately. CSV does not transfer database forms, queries, relationships, or a complete .accdb, .mdb, or .odb project.
