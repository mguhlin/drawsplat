    What you get

    Four ways to run SplatWorks

    Use the same downloads offline on your computer or on a web server. Choose the setup below that matches your needs. Google Apps Script and MySQL add connected services to DrawSplat; they are not required for local use of DrawSplat or SplatWorks.

    Path 1

    Offline on this computer

    Extract the entire ZIP and open START-HERE.html. Use the included local launcher to open the app in your browser at a local address. No hosting account or internet connection is needed for core local work.

    • Install Python 3 before going offline; no extra Python packages are needed.
    • Windows: run START-WINDOWS.bat. macOS: open START-MAC.command. Linux: run sh start-local.sh.
    • Keep the launcher window open while working. See START-HERE.html for troubleshooting.
    • Use this path for complete DrawSplat, SplatWorks, individual media apps, and collections. PDFSplat and CipherSplat’s dedicated offline edition also support direct-file opening.
    • Online services and external links require internet access. Download speech models before offline use; recording permissions still apply.
    Path 2

    Self-host on a web server

    Upload the included folders to your static web host, keeping their paths intact. Open the app through its web address. Use the same ZIP as the offline installation; the Python launcher is not needed on the server.

    • Best for access through a shared website or school network.
    • Use HTTPS for browser features that require a secure connection, such as camera and microphone access.
    • Static hosting alone does not provide shared accounts or cloud storage.
    • Follow the modular installation guide. Install the complete ecosystem or whichever component packages you need.
    Path 3

    DrawSplat with Google Apps Script

    Paste apps-script/Code.gs into a new Apps Script project bound to a Google Sheet, deploy as Web App, paste the deployment URL into Teacher Admin. Storage stays inside the district’s Google Workspace tenant.

    • Best for K–12 districts already on Google Workspace.
    • Full Compliance Console + Family Access Tools + District Privacy Packet.
    • Follow Apps Script Setup Guide.
    Path 4

    DrawSplat with MySQL online saving

    Private account-owned Save/Open through the same API on Railway, DigitalOcean, or an existing MySQL server. Added audio/video notes travel with the board; revision checks protect newer online copies.

    • Use the current repository source or build a fresh bundle. The v3.1.44 full package includes this connection and the latest backend configuration.
    • Requires Docker or Node.js 22+, MySQL 8, and a public HTTPS API.
    • Includes verified database TLS, automatic migrations, Railway configuration, and Docker Compose with an optional HTTPS proxy.
    • Google classroom rooms, templates, moderation, and turn-in/review are not connected to MySQL. Advanced district modules need separate validation.
    • Follow the MySQL Setup Guide, then Test & Enable Online Saving.

    License & support

    Free, plus optional paid services

    DrawSplatTM is released under the GNU AGPL-3.0-or-later unless a file or subdirectory says otherwise. GridSplatTM, ShowSplatTM, WriteSplatTM, and ListSplatTM / SplatWorksTM app code is GPL-3.0-only. Schools, organizations, and districts may use, host, modify, and redistribute the packages under those licenses. If you’d like hands-on setup help, a compliance review, an admin training session, or custom development, request a quote from the Contact / Information Request page.

    Optional starter database

    For manual MariaDB/MySQL installations, download drawsplat-starter.sql with all current tables and basic settings. Import into a new empty database, then finish /setup to create your administrator. Import instructions. Standard automatic setup already initializes the database.

    Typing Games: four independent adventures

    Cipher Chase adds TEKS definitions and a sound test. Wordfall Reactor defaults to everyday words against a computer, with optional TEKS sets and definition-only hints. Story Sprint blocks pasted answers while keeping classroom imports. Paws & Keys Adventure adds 12 kitten-and-puppy trails for ages 4–9. All four include instructions and language options.

    Choose a game · Read the walkthrough. The full DrawSplat and Games v3.1.44 ZIPs include these games and their shared assets. For local use, extract the whole ZIP and use the included Python 3 launcher.

    October 9 creative-tool updates

    PDFSplat converts supported documents and images locally, places text and signatures where you click or tap, edits text on the page, preserves page orientation, and saves PNG, JPG, or WebP. ImageSplat adds reversible photo adjustments, VideoSplat adds timeline markers, AudioSplat adds clip and selection analysis, and ShowSplat imports and exports WebDeck v5 with searchable slide navigation. Action icons keep visible labels.

    Complex Office and ebook layouts may differ after conversion. The current packages include these changes and their shared dependencies. Read the walkthrough and limits · Release notes.

    PDF presentation tools in v3.1.44

    PDFSplat adds Present PDF, browser full screen, black/white blanking, timed slideshows with optional looping, and self-contained WebDeck v5 export. The PDFSplat, Tools, and full DrawSplat packages include these controls. Classroom walkthrough.
