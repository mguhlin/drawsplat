    SplatWorks™

    Office apps in the SplatWorks ecosystem.

    SplatWorks includes the DrawSplat whiteboard, standalone creative and productivity tools, classroom widgets, games, and these five office apps. Browse the whole ecosystem or explore the office apps below. The ecosystem name does not change component licenses.

    Launch GridSplat™ Launch ShowSplat™ Launch WriteSplat™ Launch ListSplat™ Launch LayoutSplat™

    Apps

    Move between SplatWorks tools from one place.

    PlanSplat, GridSplat, ShowSplat, WriteSplat, ListSplat, and LayoutSplat are available as browser-based SplatWorks apps. Follow the SplatWorks development roadmap for future work.

    Student planner

    PlanSplat

    Organize assignments, exams, courses, weekly study blocks and routines. Focus on a task with a study timer. Connect Google for planner autoload and autosave; reconnect when Google authorization expires.

    LayoutSplat™

    Design with 126 distinct compositions, Avery labels and name badges, linked rich text, rulers, guides, master pages, tables, and mail merge. Import Publisher files inside the browser without LibreOffice, exchange JSON and layout files, and export print proofs, HTML, and Pack and Go. Check documented conversion limits.

    Choose an app for your classroom

    • LayoutSplat feature guide: publications, labels, typography, local imports and print output.
    • WriteSplat feature guide: drafts, handouts, readability and writing activities.
    • ListSplat feature guide: catalogs, observations, vocabulary banks and structured records.
    • ShowSplat feature guide: lessons, student presentations and portable WebDeck slides.
    • GridSplat feature guide: calculations, surveys, charts and picture graphs.

    Save a file to Google Drive

    Save native office projects, edited PDFs, VideoSplat projects or rendered videos, MediaSplat outputs and subtitles, Markdown source, concept maps and Mermaid diagram source to your Google account. Local downloads and browser drafts remain available. These actions save a new file copy and do not enable sharing.

    Google Drive guide: steps, app formats, reopening files, troubleshooting and district setup. PDFSplat, VideoSplat and MediaSplat use a separate authorization window; choose Continue with Google there, then return to the editor for the save result.

    Install and save your work

    Launch these browser apps without installing a database or creating an account. For district hosting, use the complete suite Quick Start and choose the SplatWorks components; Docker and native installation paths are available. For individual static apps, use modular self-hosting and Downloads.

    Export project files regularly. Browser autosave is specific to your device and browser and can be lost when browser data is cleared. District whiteboard accounts and classrooms do not automatically provide cloud saving for every SplatWorks app.

    See Licensing for the suite and component license notices, and Compliance and district review for deployment responsibilities.

    Work with Microsoft Office and LibreOffice

    WriteSplat exchanges DOCX/ODT documents; GridSplat exchanges XLSX/ODS spreadsheets; ShowSplat exchanges PPTX/ODP slides; ListSplat exchanges CSV table records for Access/Base. Keep the original file and check conversions. See the format comparison and limits.
